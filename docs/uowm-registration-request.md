Θέμα: Αίτημα εγγραφής εφαρμογής OpenID Connect στο sso.uowm.gr (Discord Τμήματος Πληροφορικής)

Καλησπέρα σας,

Είμαι φοιτητής του Τμήματος Πληροφορικής και μέλος της ομάδας που διαχειρίζεται τον Discord server «Πληροφορική UoWM». Ο server έχει περίπου 100 μέλη και χρησιμοποιείται για την επικοινωνία φοιτητών και διδασκόντων του Τμήματος.

Θα θέλαμε να ζητήσουμε την εγγραφή μιας εφαρμογής (client) OpenID Connect στην Κεντρική Υπηρεσία Πιστοποίησης (sso.uowm.gr). Με αυτόν τον τρόπο μπορούμε να επιβεβαιώνουμε ότι ένα μέλος του server είναι πράγματι φοιτητής του Τμήματος ή μέλος του προσωπικού, χωρίς να ζητάμε ή να χειριζόμαστε ποτέ κωδικούς πρόσβασης. Η εφαρμογή βασίζεται σε λογισμικό ανοιχτού κώδικα (άδεια MIT) που χρησιμοποιείται ήδη με τον ίδιο τρόπο στο Τμήμα Μηχανικών Πληροφορικής και Ηλεκτρονικών Συστημάτων του Διεθνούς Πανεπιστημίου της Ελλάδος.

Πώς λειτουργεί:
- Ο χρήστης λαμβάνει από το bot του Discord έναν προσωπικό σύνδεσμο μίας χρήσης, με ισχύ 10 λεπτών.
- Ο σύνδεσμος τον μεταφέρει στην επίσημη σελίδα σύνδεσης sso.uowm.gr. Ο κωδικός εισάγεται μόνο εκεί.
- Μετά τη σύνδεση, ο server μας λαμβάνει μόνο τα απαραίτητα χαρακτηριστικά και αποδίδει τον αντίστοιχο ρόλο στο Discord.

Τεχνικά στοιχεία:
- Redirect URI: https://<DOMAIN>/callback
- Ροή: Authorization Code με PKCE (S256), confidential client, πιστοποίηση client_secret_basic
- Subject type: pairwise, εφόσον είναι δυνατό
- Χαρακτηριστικά που χρειαζόμαστε: eduPersonAffiliation (ή eduPersonPrimaryAffiliation), eduPersonScopedAffiliation ή schacHomeOrganization, και ένα χαρακτηριστικό που δηλώνει το Τμήμα φοίτησης
- Δεν χρειαζόμαστε ονοματεπώνυμο, email, τηλέφωνο ή αριθμό μητρώου.

Θα σας παρακαλούσαμε να μας ενημερώσετε:
1. Ποιο scope πρέπει να ζητήσουμε για την αποδέσμευση των παραπάνω χαρακτηριστικών.
2. Ποιο χαρακτηριστικό δηλώνει το Τμήμα φοίτησης (π.χ. schGrAcEnrollment) και ποια μορφή έχει η τιμή του για το Τμήμα Πληροφορικής.
3. Αν προτιμάτε κάποιο άλλο πρωτόκολλο (CAS ή SAML) για μια εφαρμογή αυτού του μεγέθους.

Προστασία δεδομένων:
- Αποθηκεύουμε μόνο το αναγνωριστικό του λογαριασμού Discord, ένα μη αναστρέψιμο κρυπτογραφικό hash (HMAC) του αναγνωριστικού του ιδρυματικού λογαριασμού, την ιδιότητα (φοιτητής ή προσωπικό) και την ημερομηνία επιβεβαίωσης.
- Το hash χρησιμοποιείται μόνο ώστε κάθε ιδρυματικός λογαριασμός να συνδέεται με έναν λογαριασμό Discord.
- Ο χρήστης μπορεί να διαγράψει τα δεδομένα του οποιαδήποτε στιγμή με την εντολή /unverify. Τα δεδομένα διαγράφονται επίσης αυτόματα όταν αποχωρήσει από τον server.
- Δεν αποθηκεύουμε access ή refresh tokens και δεν μοιραζόμαστε δεδομένα με τρίτους.

Ο κώδικας είναι διαθέσιμος για έλεγχο στο https://github.com/michadasis/UoWM-Auth-Discord-Bot. Είμαστε στη διάθεσή σας για οποιαδήποτε διευκρίνιση ή αλλαγή κρίνετε απαραίτητη.
